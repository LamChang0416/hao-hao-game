# 澔澔遊戲大世界 🌈 (HaoHao Game World)

這是一套專為澔澔打造的高品質 Web 學習遊戲系列，結合了 **Matter.js** 物理引擎與 **Three.js** 3D 視覺特效！

## 🚀 立即開始遊戲
您可以透過 GitHub Pages 直接在線玩這些遊戲：
[https://LamChang0416.github.io/hao-hao-game/](https://LamChang0416.github.io/hao-hao-game/)

## 🎮 遊戲內容
1. **星際數字探險 (100.html)**：在閃爍的星空中，尋找神秘的能量數字！🚀
2. **平衡吧！阿布 (balance.html)**：Matter.js 物理挑戰！幫阿布在空中抓星星。⭐
3. **阿布 3D 魔術方塊 (logic.html)**：進階空間挑戰！在 3D 世界蓋出神奇形狀。🧱
4. **阿布超市小星探 (math.html)**：推著推車去數數！真實物理購物的趣味體驗。🍎
5. **阿布太空巡邏隊 (shoot.html)**：拉動重力彈弓！向宇宙發射能量星，收集祕寶。🎯
6. **阿布時光探險家 (time.html)**：啟動 3D 時光機！跨越恐龍時代與未來城市。⏳
7. **阿布蓋房子 (build.html)**：拖拉積木！幫阿布蓋出夢幻新家，5 個故事關卡！🏗️
8. **阿布棒球：魔球大挑戰 (baseball.html)**：揮棒打擊！練習快速辨認「顏色 + 形狀」的組合。⚾
9. **阿布加法魔法學校 (add.html)**：大的念嘴巴，小的比出來！跟阿布學手指加法魔法！🎩
10. **阿布ㄅㄆㄇ大冒險 (zhuyin.html)**：一二年級必備！聽音選聲調、組合拼音積木、用語音念出來！🔠
11. **阿布的星際煉金爐 (alchemy.html)**：太空船沒電了！看數字加上多少會變成十，煉出藍水晶吧！⚗️

## ✨ 技術亮點
- **物理擬真**：使用 Matter.js 實現真實的碰撞與重力感。
- **3D 視覺**：使用 Three.js 提供沉浸式的 3D 背景與門戶特效。
- **專業引導**：整合 Web Speech API 提供溫柔的語音教學與鼓勵。
- **現代介面**：採用 Tailwind CSS 與 Glassmorphism 毛玻璃設計。
